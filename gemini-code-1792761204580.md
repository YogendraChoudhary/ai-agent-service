# Eddyter AI Agent Service — Mode 8: Deterministic Editable UI Design Engine (`docs/design_canvas_plan.md`)

## 1. Executive Summary & Architectural Principles

This specification defines **Mode 8: Editable UI Design Engine (`src/design_canvas`)** for the Eddyter AI Agent Service. It allows users to attach a reference UI screenshot (e.g., an onboarding card, hero section, or feature callout) or write a design prompt, and receive a **100% editable, structured UI Component AST (`DesignDocumentAST`)** rendered directly inside Eddyter's Lexical `HtmlCanvasNode`.

The subsystem strictly adheres to Eddyter’s core engineering invariants:
1. **Zero New HTTP Endpoints**: Integrates directly into `POST /agent/stream` (primary) and `POST /agent/process` (synchronous fallback) so the frontend uses its single unified SSE/REST lifecycle.
2. **100% Deterministic Intent Routing**: A compiled, sub-millisecond regex and attachment state machine (`src/design_intent.py`) decides when to trigger Design Mode **before** any LLM is called. Nothing is left to stochastic model routing or tool-calling decisions.
3. **Code Owns Structure, Models Own Tokens**: Instead of generating brittle raw HTML or flat raster images, the agent outputs a strictly validated Pydantic Component AST where every text span, container layout, icon button, and multi-layer SVG vector path has a stable semantic `id` for click-to-edit manipulation.
4. **Loop Prompting & Self-Healing Harness**: Every generation and edit passes through a closed-loop **Draft ➔ Pydantic Parse ➔ Deterministic Domain Lint (WCAG Contrast + SVG XSS + Unique IDs) ➔ XML-Fenced Error Repair ➔ Code Auto-Heal** harness.

## 2. Route Integration (`POST /agent/stream` & `POST /agent/process`)

No new FastAPI routes are added. The engine hooks directly into the existing agent execution pipeline in `api.py` and `src/text_processing_agent.py`.

### 2.1 Why `POST /agent/stream` is the Primary Route
* **Unified Editor Command Bar**: When a user types a prompt or drops a screenshot into the Eddyter command bar, the browser client always opens an SSE stream to `POST /agent/stream`.
* **Proxy Timeout Prevention**: Multimodal vision analysis + 2-pass validation/repair takes `2.5s – 6.0s`. Emitting an immediate `event: init` over SSE prevents Cloudflare/ALB idle connection timeouts.
* **Native Repair Swapping**: Supports `event: design_ready` and `event: content_replace` out of the box, plus mid-flight cancellation via `POST /agent/abort`.

### 2.2 SSE Event Contract (`POST /agent/stream`)
When `plan.execution_mode == "design_canvas"`, `/agent/stream` emits:

```text
event: init
data: {"request_id": "req_88f1", "model": "claude-opus-5", "provider": "claude", "mode": "design_canvas"}

event: design_ready
data: {"block_type": "eddyter_design_canvas", "version": "1.0", "design_id": "dsn_ask_anything", "title": "Ask Anything Card", "theme_palette": ["#000000", "#34F5A6", "#E2FFF3", "#FFFFFF", "#8E8E93"], "root": {...}}

event: complete
data: {"total_tokens": 1120, "elapsed_seconds": 3.18, "mode": "design_canvas", "warnings": []}
```

### 2.3 Synchronous Parity (`POST /agent/process`)
When invoked via `POST /agent/process`, the exact same harness runs and returns the serialized `DesignDocumentAST` JSON inside the standard response payload for automated testing and headless integrations.

## 4. 100% Deterministic Intent Detection (`src/design_intent.py`)

To ensure the LLM never randomly decides whether to generate text, code, a flat S3 raster image, or an editable UI design, `detect_design_intent()` runs in `< 0.05ms` inside `src/request_plan.py` **before** model routing.

```python
import re
from dataclasses import dataclass
from typing import Literal, Optional

# 1. Start-Anchored UI / Design Action Verbs
_DESIGN_ACTION_RE = re.compile(
    r"^\s*(?:please\s+)?(?:can\s+you\s+|could\s+you\s+)?"
    r"(?:design|create|build|make|generate|recreate|replicate|clone|convert|turn|draft|mock\s*up|wireframe|edit|update|modify|change)\b",
    re.IGNORECASE,
)

# 2. Target UI / Editable Canvas Artifacts
_DESIGN_ARTIFACT_RE = re.compile(
    r"\b(?:"
    r"ui|user\s+interface|ux|wireframe|mockup|mock-up|"
    r"hero\s+section|landing\s+section|onboarding\s+card|feature\s+card|pricing\s+card|callout\s+card|card\s+layout|"
    r"banner\s+design|carousel\s+slide|modal\s+dialog|popup\s+layout|dashboard\s+widget|"
    r"editable\s+design|editable\s+ui|editable\s+card|editable\s+layout|editable\s+banner|canvas\s+design|"
    r"screen\s+design|app\s+screen|web\s+section"
    r")\b",
    re.IGNORECASE,
)

# 3. Multimodal Vision Recreation Cues (When user attaches a reference UI image)
_VISION_RECREATE_RE = re.compile(
    r"\b(?:"
    r"like\s+this\s+(?:image|photo|screenshot|design|ui|picture)|"
    r"from\s+this\s+(?:image|photo|screenshot|design|ui)|"
    r"match(?:ing)?\s+this\s+(?:design|layout|style|screenshot)|"
    r"recreate\s+this|replicate\s+this|clone\s+this|make\s+it\s+editable"
    r")\b",
    re.IGNORECASE,
)

# 4. Hard Negative Guards (Prevent collisions with Mode 5 Code Engine or Mode 7 Raster Photo Gen)
_NEGATIVE_CODE_GUARD_RE = re.compile(
    r"\b(?:python|typescript|javascript|rust|golang|sql|bash|dockerfile|react\s+hook|function|class|algorithm|regex|api\s+endpoint|unit\s+test)\b",
    re.IGNORECASE,
)

_NEGATIVE_RASTER_PHOTO_GUARD_RE = re.compile(
    r"\b(?:photorealistic|oil\s+painting|watercolor|8k\s+photo|cinematic\s+lighting|portrait\s+of|landscape\s+photo|anime\s+style)\b",
    re.IGNORECASE,
)

@dataclass(frozen=True)
class DesignIntentDecision:
    is_design_request: bool
    sub_mode: Optional[Literal["create_from_prompt", "create_from_vision", "edit_existing_ast"]] = None
    reason: str = ""

def detect_design_intent(
    query: str,
    operation_type: str = "general",
    has_image_attachment: bool = False,
    has_existing_design_ast: bool = False,
) -> DesignIntentDecision:
    """
    Deterministic, zero-LLM intent classifier for Mode 8 Editable UI Design.
    """
    clean_q = (query or "").strip()

    # Rule 0: Explicit operation override or active AST selection in the editor
    if operation_type in ("generate_design", "edit_design"):
        mode = "edit_existing_ast" if has_existing_design_ast else (
            "create_from_vision" if has_image_attachment else "create_from_prompt"
        )
        return DesignIntentDecision(True, mode, "explicit_operation_type")

    if has_existing_design_ast and _DESIGN_ACTION_RE.search(clean_q):
        return DesignIntentDecision(True, "edit_existing_ast", "active_design_ast_mutation")

    # Rule 1: Negative Guards (Code & Photorealistic Raster Images take precedence)
    if _NEGATIVE_CODE_GUARD_RE.search(clean_q):
        return DesignIntentDecision(False, None, "blocked_by_code_guard")
    if _NEGATIVE_RASTER_PHOTO_GUARD_RE.search(clean_q):
        return DesignIntentDecision(False, None, "blocked_by_raster_photo_guard")

    # Rule 2: Multimodal Reference Screenshot + UI/Recreation Cue
    if has_image_attachment and (
        _VISION_RECREATE_RE.search(clean_q) or _DESIGN_ARTIFACT_RE.search(clean_q)
    ):
        return DesignIntentDecision(True, "create_from_vision", "vision_attachment_plus_ui_cue")

    # Rule 3: Start-Anchored Design Verb + UI Artifact Keyword
    if _DESIGN_ACTION_RE.search(clean_q) and _DESIGN_ARTIFACT_RE.search(clean_q):
        return DesignIntentDecision(
            True,
            "create_from_vision" if has_image_attachment else "create_from_prompt",
            "action_verb_plus_ui_artifact",
        )

    return DesignIntentDecision(False, None, "no_design_pattern_matched")
```

### Planner & Router Wiring (`src/request_plan.py` & `src/task_router.py`)
When `detect_design_intent()` returns `is_design_request=True`:
* `plan.execution_mode = "design_canvas"`
* `plan.image_count = 0` (Disables S3 raster image generation tools)
* `plan.needs_web = False` (Disables DuckDuckGo/web scraping tools)
* `plan.model_tier = "advanced"`
* **Task Router Fallback Tree**: Routes to **Claude** (`claude-opus-5`) ➔ **Gemini** (`gemini-3.8-flash`) ➔ **OpenAI** (`gpt-5.2`).

## 5. Editable UI Component AST Schema (`src/design_canvas/schema.py`)

Every visual and textual element in the returned design is decomposed into a typed node with a unique `id`:
* **Split-Color Typography (`TextSpan`)**: Enables dual-tone headers (e.g., muted grey `"As"` `#8E8E93` + bold white `"k Anything"` `#FFFFFF`) where each span's text and color can be edited independently.
* **Multi-Layer Editable Vectors (`VectorIllustrationNode` & `SVGLayer`)**: Deconstructs central illustrations (e.g., overlapping mint speech bubbles `#34F5A6` and `#E2FFF3` with inner chat lines `#228B60`) into discrete, selectable vector layers so users can recolor or resize individual shapes without regenerating the graphic.
* **Interactive Controls (`IconButtonNode`, `ButtonNode`, `DividerNode`)**: Represents navigation arrows (`←`, `→`), CTAs, and section dividers as native editor primitives.

```python
from typing import Annotated, Dict, List, Literal, Optional, Union
from pydantic import BaseModel, Field

HEX_COLOR_PATTERN = r"^#[0-9A-Fa-f]{6}([0-9A-Fa-f]{2})?$"

class TextSpan(BaseModel):
    text: str = Field(..., min_length=1)
    color: str = Field("#FFFFFF", pattern=HEX_COLOR_PATTERN)
    font_weight: Literal["normal", "medium", "semibold", "bold"] = "normal"
    italic: bool = False
    underline: bool = False

class SpacingBox(BaseModel):
    top: int = Field(0, ge=0, le=256)
    right: int = Field(0, ge=0, le=256)
    bottom: int = Field(0, ge=0, le=256)
    left: int = Field(0, ge=0, le=256)

class NodeStyle(BaseModel):
    background_color: Optional[str] = Field(None, pattern=HEX_COLOR_PATTERN)
    padding: SpacingBox = Field(default_factory=SpacingBox)
    border_radius: int = Field(0, ge=0, le=999)
    border_color: Optional[str] = Field(None, pattern=HEX_COLOR_PATTERN)
    border_width: int = Field(0, ge=0, le=16)
    max_width: Optional[int] = Field(None, ge=40, le=1440)
    width_percent: Optional[int] = Field(None, ge=10, le=100)

class TextNode(BaseModel):
    node_type: Literal["text"] = "text"
    id: str = Field(..., pattern=r"^[a-z0-9_]{2,40}$")
    tag: Literal["h1", "h2", "h3", "p", "span", "caption"]
    spans: List[TextSpan] = Field(..., min_length=1)
    align: Literal["left", "center", "right"] = "center"
    font_size_px: int = Field(16, ge=10, le=96)
    line_height: float = Field(1.5, ge=1.0, le=2.5)
    style: NodeStyle = Field(default_factory=NodeStyle)
    editable: bool = True

class DividerNode(BaseModel):
    node_type: Literal["divider"] = "divider"
    id: str = Field(..., pattern=r"^[a-z0-9_]{2,40}$")
    color: str = Field("#2C2C2E", pattern=HEX_COLOR_PATTERN)
    thickness_px: int = Field(1, ge=1, le=8)
    width_percent: int = Field(75, ge=10, le=100)
    margin_y_px: int = Field(16, ge=0, le=128)
    editable: bool = True

class SVGLayer(BaseModel):
    layer_id: str = Field(..., pattern=r"^[a-z0-9_]{2,40}$")
    label: str
    svg_element: Literal["path", "circle", "rect", "ellipse"]
    attributes: Dict[str, Union[str, int, float]]
    fill_color: str = Field(..., pattern=HEX_COLOR_PATTERN)
    stroke_color: Optional[str] = Field(None, pattern=HEX_COLOR_PATTERN)
    stroke_width: float = Field(0.0, ge=0.0, le=20.0)
    opacity: float = Field(1.0, ge=0.0, le=1.0)

class VectorIllustrationNode(BaseModel):
    node_type: Literal["vector_illustration"] = "vector_illustration"
    id: str = Field(..., pattern=r"^[a-z0-9_]{2,40}$")
    view_box: str = Field("0 0 200 180", pattern=r"^\d+\s+\d+\s+\d+\s+\d+$")
    width_px: int = Field(180, ge=24, le=800)
    height_px: int = Field(160, ge=24, le=800)
    layers: List[SVGLayer] = Field(..., min_length=1, max_length=24)
    editable: bool = True

class IconButtonNode(BaseModel):
    node_type: Literal["icon_button"] = "icon_button"
    id: str = Field(..., pattern=r"^[a-z0-9_]{2,40}$")
    icon_name: Literal[
        "arrow_left", "arrow_right", "chevron_left", "chevron_right",
        "plus", "close", "check", "sparkles", "search", "send"
    ]
    color: str = Field("#FFFFFF", pattern=HEX_COLOR_PATTERN)
    size_px: int = Field(24, ge=12, le=64)
    aria_label: str = "Action"
    style: NodeStyle = Field(default_factory=NodeStyle)
    editable: bool = True

class ButtonNode(BaseModel):
    node_type: Literal["button"] = "button"
    id: str = Field(..., pattern=r"^[a-z0-9_]{2,40}$")
    label: str = Field(..., min_length=1)
    text_color: str = Field("#000000", pattern=HEX_COLOR_PATTERN)
    font_size_px: int = Field(15, ge=12, le=32)
    font_weight: Literal["normal", "medium", "semibold", "bold"] = "semibold"
    style: NodeStyle = Field(default_factory=NodeStyle)
    editable: bool = True

class ContainerNode(BaseModel):
    node_type: Literal["container"] = "container"
    id: str = Field(..., pattern=r"^[a-z0-9_]{2,40}$")
    layout: Literal["flex_col", "flex_row", "grid"] = "flex_col"
    align_items: Literal["start", "center", "end", "stretch"] = "center"
    justify_content: Literal["start", "center", "end", "space_between", "space_around"] = "center"
    gap_px: int = Field(16, ge=0, le=128)
    style: NodeStyle = Field(default_factory=NodeStyle)
    children: List["DesignNode"] = Field(..., min_length=1, max_length=25)

DesignNode = Annotated[
    Union[
        ContainerNode,
        TextNode,
        DividerNode,
        VectorIllustrationNode,
        IconButtonNode,
        ButtonNode,
    ],
    Field(discriminator="node_type"),
]
ContainerNode.model_rebuild()

class DesignDocumentAST(BaseModel):
    block_type: Literal["eddyter_design_canvas"] = "eddyter_design_canvas"
    version: Literal["1.0"] = "1.0"
    design_id: str
    title: str
    theme_palette: List[str] = Field(..., min_length=2, max_length=10)
    root: ContainerNode
```

### 6.1 XML-Fenced Repair Prompt (`src/design_canvas/prompts.py`)

```python
def build_design_repair_prompt(errors: list[str]) -> str:
    formatted_errors = "\n".join(f"  - {err}" for err in errors)
    return (
        "<harness_validation_failure>\n"
        "Your previous JSON output failed deterministic verification with the following exact errors:\n"
        f"{formatted_errors}\n"
        "</harness_validation_failure>\n\n"
        "REPAIR INSTRUCTIONS:\n"
        "1. Modify ONLY the failing nodes, IDs, colors, or attributes listed inside <harness_validation_failure>.\n"
        "2. Do NOT alter valid sibling nodes, text content, or layout hierarchy.\n"
        "3. Return ONLY the complete, valid raw JSON object conforming to DesignDocumentAST with zero markdown wrappers."
    )
```

### 6.2 Harness Orchestrator (`src/design_canvas/service.py`)

```python
from typing import Optional
from pydantic import ValidationError
from src.design_canvas.schema import DesignDocumentAST
from src.design_canvas.validate import validate_design_ast, auto_heal_design_ast
from src.design_canvas.prompts import (
    DESIGN_SYSTEM_PROMPT,
    build_initial_design_prompt,
    build_design_repair_prompt,
)

MAX_DESIGN_REPAIR_ATTEMPTS = 2

async def execute_design_canvas_harness(
    agent_runner,
    user_query: str,
    sub_mode: str,
    reference_image_bytes: Optional[bytes] = None,
    existing_ast_json: Optional[str] = None,
) -> DesignDocumentAST:
    vision_meta = None
    if reference_image_bytes:
        from src.design_canvas.vision_extractor import extract_vision_metadata
        vision_meta = extract_vision_metadata(reference_image_bytes)

    conversation = [
        {"role": "system", "content": DESIGN_SYSTEM_PROMPT},
        {
            "role": "user",
            "content": build_initial_design_prompt(
                user_query=user_query,
                sub_mode=sub_mode,
                vision_meta=vision_meta,
                existing_ast_json=existing_ast_json,
            ),
        },
    ]

    last_parsed_ast: Optional[DesignDocumentAST] = None

    for attempt in range(MAX_DESIGN_REPAIR_ATTEMPTS + 1):
        raw_output = await agent_runner.run_json_completion(
            messages=conversation,
            image_bytes=reference_image_bytes if attempt == 0 else None,
            temperature=0.1 if attempt > 0 else 0.2,
        )
        clean_json = _strip_markdown_fences(raw_output)

        # Stage A: Pydantic Structural Validation
        try:
            candidate_ast = DesignDocumentAST.model_validate_json(clean_json)
            last_parsed_ast = candidate_ast
        except ValidationError as exc:
            schema_errors = [
                f"SCHEMA_ERROR at `{'.'.join(str(p) for p in e['loc'])}`: {e['msg']}"
                for e in exc.errors()[:8]
            ]
            conversation.append({"role": "assistant", "content": clean_json})
            conversation.append({"role": "user", "content": build_design_repair_prompt(schema_errors)})
            continue

        # Stage B: Deterministic Domain Validation (WCAG Contrast, SVG Security, Unique IDs)
        domain_errors = validate_design_ast(
            candidate_ast,
            vision_meta=vision_meta,
            existing_ast_json=existing_ast_json,
        )
        if not domain_errors:
            return candidate_ast

        conversation.append({"role": "assistant", "content": clean_json})
        conversation.append({"role": "user", "content": build_design_repair_prompt(domain_errors)})

    # Stage C: Deterministic Code Auto-Healer (Guarantees zero 500 failures if parsed)
    if last_parsed_ast is not None:
        return auto_heal_design_ast(last_parsed_ast, vision_meta=vision_meta)

    raise ValueError("DesignDocumentAST failed schema validation after maximum repair attempts.")
```
